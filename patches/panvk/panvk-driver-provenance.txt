This library is used only inside this application. It does not replace the
Android system driver. System Vulkan has priority; a separate process checks
the alternative's device creation, DXVK features, transfer and display sharing
before selecting it. A failed check retains the available fallback. Device
family detection alone does not enable the driver. No game executable is patched.

Upstream device tests are not WoW Imito device tests. Mali game performance
and rendering correctness require confirmation on the affected hardware.
