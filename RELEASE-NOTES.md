# WoW Imito 1.3.9

## Fixes

- Fixed a graphics check that could unnecessarily switch compatible devices from **Vulkan to OpenGL**.
- Vulkan now correctly treats optional texture filtering as optional. Required graphics features and display checks still have to pass; OpenGL remains the fallback when needed.

Applies to **Vanilla, The Burning Crusade and Wrath of the Lich King** on Android 12+ ARM64 devices.
