# WoW Imito

**あなたのアゼロス。あなたのキャラクター。今度は Android で。**

Android のスマートフォン、タブレット、携帯型ゲーム機で、オリジナル版やカスタム版の World of Warcraft クライアントを実行できます。公式 Battle.net でログインやアップデートを行う WoW Forever にも対応しています。Imito Touch UI またはコントローラーで操作でき、2 画面の携帯型ゲーム機では第 2 画面の HUD に情報をリアルタイムで表示できます。Vanilla、TBC、WotLK、各サーバー専用のバージョンについては、[対応クライアント](#compatibility)をご覧ください。プレイ中に PC は必要ありません。

**[APK をダウンロード](https://github.com/MrAnonymz/WoW-Imito/releases/latest)** · **[最新のパッチノート](https://github.com/MrAnonymz/WoW-Imito/releases/latest)** · **[すべてのリリース](https://github.com/MrAnonymz/WoW-Imito/releases)**

> [!IMPORTANT]
> **不具合が見つかったら、WoW Imito の Settings > Report problem を開いてください。** 何が起きたか、そのとき何をしていたかを記入してください。原因の調査に役立つよう、アプリがデバイスとゲームの情報を報告に添付します。
>
> **新機能や、ほかのデバイス・ゲームクライアントへの対応を要望する場合**は、**Other** を選び、追加してほしい内容を記入してください。
>
> WoW Imito が開かない場合は、[GitHub で issue を作成](https://github.com/MrAnonymz/WoW-Imito/issues/new/choose)し、デバイスの機種名、Android のバージョン、アプリのバージョン、表示されるエラーを記載してください。

## プレイを始める

**Android 12 以降、ARM64 プロセッサー、64 ビット版 Android が必要です。Forever には 8 GB 以上の RAM が必要です。** ゲームファイルとサーバーのアカウントは含まれていません。

1. WoW Imito をインストールして開きます。
2. サーバーが指定するクライアントのファイル一式を内部ストレージまたは SD カードにコピーするか、**Game files** から ZIP をダウンロードします。**Forever** はクライアント一覧から選択してください。ログイン、ダウンロード、アップデートは公式 Battle.net が行います。初回のセットアップには数分かかることがあります。
3. 検出されたクライアントを選び、確認画面が表示されたらサーバーアドレスを確認します。フォルダーを手動で選ぶには **Game files**、サーバーを変更するには **Settings > Set realm** を使用します。
4. **PLAY** をタップし、ログインしてキャラクターを選びます。

アプリの更新は自動で案内され、利用可能な場合はダウンロード量の少ない差分更新が使われます。自動ダウンロードとインストールを行うには、**Options > Support > Automatically update WoW Imito** を有効にしてください。Android 側で許可や確認が必要になる場合もあります。ランチャー内のアプリ名またはバージョンをタップすると、オフラインのパッチノートを読めます。

<summary><strong>ハードウェアとストレージ</strong></summary>

従来のクライアントでは、**Snapdragon 888 クラスの性能と 6 GB の RAM** が目安です。グラフィックス機能の対応状況や性能はデバイスによって異なります。

| クライアント | インストール前に確保しておきたい空き容量 |
| --- | --- |
| Vanilla / TBC | 8 GB / 12 GB |

| Wrath Rebuffed | 30 GB |
| CoA / Descension コミュニティ版クライアント | 50 GB |

必要な容量はクライアントやアップデートによって変わります。サーバーが指定するクライアントのファイル一式、インターネット接続、ご自身のアカウントを用意してください。

</details>

## 機能と操作

- **Imito Touch UI：** 移動やサイズ変更が可能な操作ボタンと、固定できるチャットを備えています。**Menu > Touch UI > Show tutorial** で操作方法を学べます。**Save & reload** でレイアウトを保存できます。
- **コントローラーとアドオン：** ConsolePort と任意のアドオンを用意しています。利用できるものはゲームクライアントによって異なります。設定方法は下記を参照してください。
- **2 画面の携帯型ゲーム機：** 独立した第 2 画面に、ミニマップ、チャット、クエスト、プレイヤーとターゲットの情報をリアルタイムで表示します。**Options > Controller > Second-screen controls** を有効にし、再接続には **Displays** を使用します。トラックパッド画面とキーボード画面も利用できます。
- **性能に関する設定：** ECO の上限を **30、40、50、60 FPS** から選択でき、**Low specs** も利用できます。従来のクライアントでは、**Options > Graphics > Graphics driver** から Android Vulkan ドライバー（**.zip / .wcp**）をインポートできます。適用前にアプリがドライバーをチェックします。既定値は引き続き **Automatic** です。
- **言語：** 英語、ドイツ語、チェコ語、ポーランド語、ロシア語、イタリア語、スペイン語、簡体字中国語、日本語、トルコ語、アラビア語に対応しています。**Options > Game > Language** でアプリ、Touch UI、オフラインのパッチノートの言語を変更できます。既定は英語です。翻訳には AI を使用しているため、誤りがあればご報告ください。

> [!TIP]
> CPU/GPU の負荷と温度を抑えるため、**Forever では ECO 30–40 FPS の使用を強くおすすめします**。性能はデバイス、設定、場面によって変わります。

<details>
<summary><strong>アドオンとコントローラーの設定</strong></summary>

任意のアドオンは**既定でオフ**です。キャラクター選択画面の **AddOns** で有効にしてください。利用できるものはクライアントによって異なります。

**Bagnon、ConsolePort、LoseControl、NotPlater、OmniCC、Titan Panel、Immersion、AtlasLoot Enhanced、GearScoreLite、Deadly Boss Mods、SexyMap、X-Perl UnitFrames。**

**MoveAnything** と **MinimapButtonBag** は**既定でオン**です。ゲーム内でアドオンを変更した後は **/reload** を実行してください。

Wrath では **Imito Touch UI** または **ConsolePort** を選び、**WoW Imito Input** は有効のままにしてください。コントローラーを接続しても、この選択は変わりません。オリジナルの Vanilla と TBC では、任意で **ConsolePort Legacy** を利用できます。無効にして再読み込みすると Touch UI に戻れます。

</details>
