# WoW Imito

**عالم أزيروث الخاص بك. شخصيتك. الآن على Android.**

شغّل عملاء World of Warcraft الأصليين والمخصصين على هواتف Android وأجهزته اللوحية وأجهزة الألعاب المحمولة، بما في ذلك WoW Forever مع تسجيل الدخول والتحديثات عبر Battle.net الرسمي. استخدم Imito Touch UI أو وحدة تحكم، مع واجهة HUD حية على الشاشة الثانية في أجهزة الألعاب المحمولة ذات الشاشتين. راجع [العملاء المدعومين](#compatibility) لمعرفة إصدارات Vanilla وTBC وWotLK والإصدارات الخاصة بالخوادم. لا تحتاج إلى كمبيوتر أثناء اللعب.

## ابدأ اللعب

**يلزم Android 12 أو أحدث، ومعالج ARM64، ونظام Android بمعمارية 64 بت. يتطلب Forever ذاكرة RAM بسعة 8 GB أو أكثر.** لا يتضمن التطبيق ملفات اللعبة أو حسابات الخوادم.

1. ثبّت WoW Imito وافتحه.
2. انسخ ملفات العميل الذي يطلبه خادمك كاملةً إلى التخزين الداخلي أو بطاقة SD، أو نزّل ملف ZIP عبر **Game files**. أما **Forever**، فاختره من قائمة العملاء؛ يتولى Battle.net الرسمي تسجيل الدخول والتنزيلات والتحديثات. قد يستغرق الإعداد الأول بضع دقائق.
3. اختر العميل الذي عثر عليه التطبيق، وأكّد عنوان خادمه عند ظهور الطلب. استخدم **Game files** لاختيار مجلد يدويًا، أو **Settings > Set realm** لتغيير الخادم.
4. اضغط **PLAY**، ثم سجّل الدخول واختر شخصيتك.

يعرض التطبيق تحديثاته تلقائيًا، ويستخدم تنزيلات تفاضلية أصغر حجمًا عند توفرها. فعّل **Options > Support > Automatically update WoW Imito** لتنزيل التحديثات وتثبيتها تلقائيًا؛ قد يظل Android بحاجة إلى إذن أو تأكيد. اضغط اسم التطبيق أو رقم إصداره في واجهة التشغيل لقراءة ملاحظات الإصدار دون اتصال.

## الميزات والتحكم

- **Imito Touch UI:** عناصر تحكم قابلة للتحريك وتغيير الحجم، مع إمكانية تثبيت نافذة الدردشة. افتح **Menu > Touch UI > Show tutorial** لتعلّم التحكم؛ يحفظ **Save & reload** ترتيب واجهتك.
- **وحدات التحكم والإضافات:** يتوفر ConsolePort وإضافات اختيارية، ويختلف توفرها بحسب عميل اللعبة؛ تفاصيل الإعداد أدناه.
- **أجهزة الألعاب المحمولة ذات الشاشتين:** عرض حي للخريطة المصغرة والدردشة والمهام ومعلومات اللاعب والهدف على شاشة ثانية مستقلة. فعّل **Options > Controller > Second-screen controls**، واستخدم **Displays** لإعادة الاتصال. تتوفر أيضًا واجهتا لوحة اللمس ولوحة المفاتيح.
- **خيارات الأداء:** حدود ECO بمعدل **30 أو 40 أو 50 أو 60 FPS**، وخيار **Low specs**، واستيراد برامج تشغيل Android Vulkan بصيغة **.zip / .wcp** للعملاء الكلاسيكيين عبر **Options > Graphics > Graphics driver**. يفحص التطبيق برنامج التشغيل قبل تطبيقه. يظل **Automatic** هو الخيار الافتراضي.
- **اللغات:** الإنجليزية والألمانية والتشيكية والبولندية والروسية والإيطالية والإسبانية والصينية المبسطة واليابانية والتركية والعربية. يغيّر **Options > Game > Language** لغة التطبيق وTouch UI وملاحظات الإصدار المتاحة دون اتصال. الإنجليزية هي اللغة الافتراضية؛ أُنجزت الترجمات بمساعدة الذكاء الاصطناعي وقد تتضمن أخطاء، لذا يُرجى الإبلاغ عنها.

> [!TIP]
> **يُنصح بشدة باستخدام ECO بمعدل 30–40 FPS في Forever** لتقليل حمل المعالج ومعالج الرسوميات ودرجات الحرارة. يعتمد الأداء على جهازك وإعداداتك والمشهد المعروض.
