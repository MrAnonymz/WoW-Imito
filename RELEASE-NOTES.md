# WoW Imito 1.5.5

## Quick fixes

- Fixed blocked or incomplete communication with the game that could cause freezes and unresponsive controls.
- Corrected unsupported Vulkan feature requests during graphics startup.
- Corrected Vulkan window-buffer formats and image layouts during presentation.
- Improved cleanup after memory allocation and runtime connection failures.
- Added more precise Vulkan startup errors to problem reports.

## Touch UI and language

- Added a language picker on first launch. Existing language choices are preserved.
- Added Reset tutorial to Touch UI settings. Saved controls and spell slots are preserved.
