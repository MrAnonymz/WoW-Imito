# WoW Imito 1.3.5

## Changes

- Added **five extra spell slots** in a second arc beside the existing buttons.
- Each **A / B / C** page now holds **11 spells**. The three item slots stay separate.
- Assign spells or macros, view cooldowns, resize the UI and move each new slot independently.
- Available in **Vanilla, The Burning Crusade and Wrath of the Lich King**.
- Existing spell assignments, saved positions and controller bindings are preserved.
