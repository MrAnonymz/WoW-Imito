# WoW Imito

**你的艾泽拉斯，你的角色，如今尽在 Android。**

在 Android 手机、平板电脑和掌机上运行原版及定制版 World of Warcraft 客户端，包括通过官方 Battle.net 登录和更新的 WoW Forever。你可以使用 Imito Touch UI 或游戏手柄，并在双屏掌机上使用实时第二屏 HUD。Vanilla、TBC、WotLK 及各服务器专用版本，请参阅[支持的客户端](#compatibility)。游玩时无需 PC。

**[下载 APK](https://github.com/MrAnonymz/WoW-Imito/releases/latest)** · **[最新更新说明](https://github.com/MrAnonymz/WoW-Imito/releases/latest)** · **[所有版本](https://github.com/MrAnonymz/WoW-Imito/releases)**

> [!IMPORTANT]
> **遇到问题了吗？请在 WoW Imito 中打开 Settings > Report problem。** 请说明发生了什么，以及问题出现时你正在进行什么操作。应用会在报告中附上设备和游戏的详细信息，帮助查明原因。
>
> 如需**提出功能建议，或请求支持其他设备或游戏客户端**，请选择 **Other**，并说明希望添加什么。
>
> 如果无法打开 WoW Imito，请[在 GitHub 上创建 issue](https://github.com/MrAnonymz/WoW-Imito/issues/new/choose)，并提供设备型号、Android 版本、应用版本及看到的错误信息。

## 开始游戏

**需要 Android 12 或更高版本、ARM64 处理器和 64 位 Android 系统。Forever 需要至少 8 GB RAM。** 本应用不包含游戏文件或服务器账号。

1. 安装并打开 WoW Imito。
2. 将服务器要求的完整客户端复制到内部存储或 SD 卡，或通过 **Game files** 下载 ZIP 文件。如需游玩 **Forever**，请在客户端列表中选择它；登录、下载和更新由官方 Battle.net 处理。首次设置可能需要几分钟。
3. 选择检测到的客户端，并在出现提示时确认服务器地址。使用 **Game files** 手动选择文件夹，或通过 **Settings > Set realm** 更改服务器。
4. 点击 **PLAY**，登录并选择角色。

应用会自动提示更新，并在有可用增量更新时下载较小的更新包。启用 **Options > Support > Automatically update WoW Imito** 可自动下载和安装；Android 仍可能要求授予权限或确认。点击启动界面中的应用名称或版本号，即可查看离线更新说明。

## 功能与操作

- **Imito Touch UI：** 控件可移动、可调整大小，聊天窗口可固定。打开 **Menu > Touch UI > Show tutorial** 学习操作；使用 **Save & reload** 保存布局。
- **手柄与插件：** 提供 ConsolePort 和可选插件，具体可用内容取决于游戏客户端；设置详情见下文。
- **双屏掌机：** 在独立的第二屏幕上实时显示小地图、聊天、任务及玩家/目标信息。启用 **Options > Controller > Second-screen controls**；使用 **Displays** 重新连接。还可切换到触控板和键盘视图。
- **性能选项：** ECO 提供 **30、40、50 或 60 FPS** 上限，另有 **Low specs** 选项。经典客户端可在 **Options > Graphics > Graphics driver** 中导入 Android Vulkan 驱动（**.zip / .wcp**）。应用会在使用驱动前对其进行检查。默认仍为 **Automatic**。
- **语言：** 英语、德语、捷克语、波兰语、俄语、意大利语、西班牙语、简体中文、日语、土耳其语和阿拉伯语。**Options > Game > Language** 可更改应用、Touch UI 和离线更新说明的语言。默认为英语；翻译使用了 AI 辅助，可能存在错误，欢迎反馈。

> [!TIP]
> **强烈建议在 Forever 中使用 ECO 30–40 FPS**，以降低 CPU/GPU 负载和温度。实际性能取决于设备、设置和场景。

<details>
<summary><strong>插件与手柄设置</strong></summary>

可选插件**默认关闭**；可在角色选择界面的 **AddOns** 中启用。可用插件因客户端而异：

**Bagnon、ConsolePort、LoseControl、NotPlater、OmniCC、Titan Panel、Immersion、AtlasLoot Enhanced、GearScoreLite、Deadly Boss Mods、SexyMap 和 X-Perl UnitFrames。**

**MoveAnything** 和 **MinimapButtonBag** **默认开启**。在游戏中更改插件后，请使用 **/reload**。

在 Wrath 中，请选择 **Imito Touch UI** 或 **ConsolePort**，并保持 **WoW Imito Input** 启用。连接手柄不会更改此选择。原版 Vanilla 和 TBC 提供可选的 **ConsolePort Legacy**；将其禁用并重新加载，即可返回 Touch UI。

</details>
