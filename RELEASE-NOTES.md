# WoW Imito 1.3.1

## Fixes

- **Client selection:** incomplete or removed clients no longer remain selectable after searching. Restored game files and reconnected storage are checked again.
- **Missing game files:** clearer guidance when a client's `Data` folder is missing.
- **Manual folder selection:** **Game files** is available in the top-right corner of both editions, separate from the private edition's account/server button.
- **Version display:** both editions now show **1.3.1**.

Open the launcher after restarting the app to check for this update.
